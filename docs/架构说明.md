# 最小验证架构

本项目使用 uni-app Vue3；手机与桌面共用页面，iCloud 仍是数据的来源。没有自建业务后端，也不依赖常开 Mac。

## Windows 当前清单自动更新

Windows 的 `loadedListRefresh` 能力在用户首次明确读取之后启用。调度器每 20 秒及本地窗口聚焦/恢复可见时，只发送带同一页面、清单句柄的 `readList/background: true`。相邻读取与刚完成的手动读取至少间隔 3 秒，不并发；隐藏、本地编辑、排序菜单、示例、选区待选择、连接恢复待核对或任何失去可写快照的状态都暂停。不自动导航、展开、重新连接或提交业务写入，Android 与鸿蒙未开放此能力。

共享适配器先核对官方页面与选区，再判断官方活动编辑框、编辑标志和可见弹层；有草稿或弹层只返回暂缓，不读取事项字段、失焦或取消它们。主进程同时以原生 `isVisible/isMinimized` 阻止隐藏/最小化窗口的新自动读取。关闭节流时网页仍可能报告可见，见 [Electron 可见性文档](https://www.electronjs.org/docs/latest/api/browser-window#page-visibility)，不能仅依赖网页状态。

回执只在区域、网络版本、原快照对象、页面与清单仍一致且没有开始编辑时应用；销毁后的回执也丢弃。成功只替换显示快照，保留搜索、视图与待核对的保存提示，不自动解除离线保护；失败保留内容并要求手动核对。原生隐藏兜底的暂缓不消耗读取间隔，恢复可见可以立即核对。这里只更新网页已经加载的当前清单，不把定时读取描述为全账户、实时云端或退出应用后的后台同步。

## 分层

1. **共用页面**：只调用 `openSite`、`execute` 等固定接口，不感知 `plus` 或 Electron。
2. **平台桥接**：Windows 使用无原生权限的独立 Electron 网页容器；Android 使用 `plusrequire: none` 的独立 WebView；鸿蒙使用 UTS 注册的独立 ArkWeb 原生组件，不使用 `plus`。鸿蒙目前只有逻辑层与资源导出证据，原生编译、登录和设备仍待验收。
3. **共用网页适配器**：递归同源 iframe，识别清单和事项，通过当前网页实际暴露的记录 ID 操作。日期只额外读取当前 DOM 行直接绑定的同一记录字段，不遍历账户根状态，也不调用私有网络接口。

## 固定命令协议

- `read`：读取清单及当前清单已加载的事项，并返回当前页面句柄。
- `selectList`：使用当前页面内的清单句柄切换清单；清单名称相同也不会混淆。
- `showCompleted`：Windows 已完成页签请求官方菜单显示完成项，绑定当前页面和清单。只接受唯一且启用的显示/隐藏动作；已经显示时不点击隐藏，不使用清除已完成动作。打开或展开期间清单变化会停止；回执仅表示请求展开，不能保证完整加载全部完成项。Android/鸿蒙未开放该命令。
- `setCompleted`：提交明确的目标完成状态，同时携带页面句柄、清单句柄、真实记录 ID、读取时的状态和内容指纹。
- `setText`：Windows 当前开放标题和备注编辑，一次只改一个字段，沿用相同的页面、清单、记录 ID、完成状态与内容指纹。标题不能为空或含换行，备注最多 2000 字；读取被截断的长备注不能覆盖。
- `setFlagged`：Windows 普通事项提交明确的布尔旗标目标与原状态，使用相同的页面、清单、记录 ID 和内容指纹。当前行的独立旗标格必须结构明确，官方详情按钮状态也须一致；只切换一次草稿并存储一次。已有编辑窗口、重复事项、歧义入口及冲突不存储。旗标状态进入事项指纹，其他字段写入也拒绝旧旗标快照；Android/鸿蒙未开放新写入命令。
- `getSchedule`：优先读取当前已加载行绑定的截止时间、全天标志与时区，验证绑定记录 ID 与该行一致。已识别绑定缺少日期而行中仍有一个日期节点时，只读打开该事项官方详情，读取唯一语义控件并取消；只接受可确认的指定时间，未知绑定、控件冲突及无法取消不返回日期。日期用公历年月日表示，全天日期没有时间和时区参数；带时间时显示并绑定本机编辑时区。
- `setSchedule`：Windows 日期编辑沿用页面、清单、记录 ID 与内容指纹，另带日期来源指纹和明确目标。详情来源需要同一页面内已读并取消的凭据，重新打开后核对原日期，开始修改即消耗凭据；伪造或复用来源指纹不能写入。通过官方开关与分段输入修改草稿，只激活一次存储；存储后再打开同一事项详情一次，核对目标、取消且确认选区和其他字段保持，才返回网页观察。冲突不补偿，不直接改 DOM 文字或调用内部写入方法。重复事项保留官方入口；Android/鸿蒙未开放新命令。
- `createItem`：Windows 已开放，绑定当前页面、清单与单次请求标识。新增按钮激活一次，只向本次唯一的新空事项输入标题；等待官方选中进入编辑，同名旧事项不会被覆盖。同一页面不接受原请求重放。新标题输入后保留编辑状态，让官方自动保存，不强制失焦提交初始记录；已通过真实本地界面、官方重载及用户独立 Mac/iPhone 核对。Android/鸿蒙未开放该命令。

事项 ID 来自网页，可能含账户相关标识，只在应用运行时使用，不进入公共测试数据或文档。清单句柄在页面重载后失效，不能持久化为云端 ID。

## 连接不可用与恢复

Windows 通过同一本地主窗口主框架和区域白名单 IPC 提供 `connectionState`，只返回 `offline/unavailable/available/unknown`。系统或官方框架明确离线时停止操作；[Electron 文档](https://www.electronjs.org/docs/latest/api/net#netisonline)说明联网标志为真不足以证明能访问目标站点，因此另在当前官方框架向同源 `/favicon.ico` 发 `HEAD`：`credentials: omit`、`cache: no-store`、手动重定向、1.2 秒中止。只检查是否得到 HTTP 响应或重定向，不读正文、响应头、Cookie 或私有接口。这个状态只证明公开资源可达，不能证明提醒事项接口可用、账号有效或写入已上云。

本地监测每秒只请求状态，公开检查成功缓存 15 秒，失败按 2、4、8、16、30 秒退避；写入、明确读取/选择和重新连接强制新检查。离线或不可达时不执行 DOM 命令或重连导航；未知状态不返回缓存快照成功，也不允许写入或重连。网络未确认时首次读取仍可创建官方窗口，返回待就绪。受限回执保留未派发状态，不借新连接自动重试。

共享适配器监听离线事件；Windows 公开检查失败也可调用固定的失效入口。失效时更换页面句柄、清除旧快照和详情日期读回凭据，旧请求不能在恢复后继续。每项命令记录连接代次；指针序列、文字原生命令、日期/清单输入、最终快捷键与只读轮询均核对当前代次，瞬断后恢复也停止后续步骤。异步轮询错误通过 Promise 拒绝回传，中途断网的写入返回不确定，不冒称尚未写入或补偿。

界面保留上次内容供查看，将本地草稿标为阻断并保留在当前窗口。可用通知不恢复写权限；只有本次断网之后发起、未再次中断的明确读取或重新连接完成，才恢复。旧读取/写入迟到回执不能解除限制，编辑仍需先核对并由用户结束，不自动保存草稿。监测不会读取事项，忽略跨区域迟到结果并在页面销毁时清理。

开发验收分开记录两种故障：会话网络模拟，以及仅对公开检查 `HEAD` 的故障注入。后者只在固定专用清单、没有本地编辑时安装单一 `onBeforeRequest` 钩子，随后无论成功失败均移除，不观察请求正文或认证头。当前应用没有其他此类钩子；[Electron 文档](https://www.electronjs.org/docs/latest/api/web-request)规定同一事件仅使用最后一个监听，后续若添加同类监听须统一管理。真实账号的公开检查故障注入不等于物理断网、系统休眠、长期或手机验收。

列表日期读取依赖当前网页的主机属性绑定结构（新旧 React 的主机属性键），不是 Apple 对外承诺的稳定 API。只沿当前行的直接子组件取同一个已加载记录，限定读取 `pk`、`DueDate`、`AllDay`、`TimeZone`；不枚举记录，不读 Fiber、内部实例、祖先或账户容器。类型、绑定或时区未知时日期不可用，不退回正文猜测。合成回归以访问陷阱验证这些边界。指定事项的详情读回独立标为 `official-details`，不把列表字段或列表排序伪装成已恢复；仅在页面内保存最多 128 份定向读回凭据，不写入存储或日志。

真实验证发现网页会把部分带时区的全天日期按 UTC 日历日显示，和独立苹果客户端相差一天。适配器使用已加载记录的时区或无时区全天语义恢复公历日期，不做统一加减一天；日期指纹覆盖时间戳、全天标志和时区。显示修正保留可识别的重复文案，格式未知时标记附注不完整。网页存储回执与独立端确认仍分别记账。

打开官方日期详情后，在任何草稿输入前再次比较详情与已读取日期。只允许完全一致，或已确认的全天 UTC 日历日显示差异；其他日期、时间和开关冲突均取消自己的草稿、不存储，并清除旧快照写权限。这项保护不能证明之前的云端清除已完成。

缺少绑定时间戳时，全天详情可能仍显示 UTC 日历日，不从它推断苹果端实际日期；关闭日期但仍存在日期节点也视为冲突。保存后复核若发现官方切换清单、事项其他字段变化、详情仍是旧时间或无法取消，返回不确定且不读取自动改选清单的事项，不把行字段清空作为单独成功证据。真实新专用事项的指定时间设置和清除已有两个 Windows 会话证据；缺失字段来源的编辑目前只有合成证据，真实仅只读验证原事项详情。

本地显示排序独立于写入协议：清单顺序直接保留当前快照次序，日期或标题排序以主事项及其连续子事项为一组移动，组内保留网页次序。同日全天事项在指定时间前，无日期主事项与日期不可读主事项分别保留在后，未知日期不从元数据文案猜测。排序不改快照或云端字段，切回清单顺序可恢复；本地固定设置键仅保存模式枚举，不保存清单、记录 ID 或事项正文。

H5 排序菜单由本地页面控制展开与焦点，方向键只改变焦点，回车或点击选项才保存排序模式；Esc、焦点离开和点击外部取消，保留搜索文字与原排序。键盘、焦点和指针监听均只装入本地页面，使用原始 DOM 事件，避免组件事件包装丢失 DOM 语义；远程 iCloud 网页不加载这些监听。非 H5 分支继续使用 uni-app 选择器。

旗标仅从当前可见事项行的 `.flag-container[role="gridcell"]` 及其直接图标子节点读取，不增加模型字段读取或网络调用。格结构缺失、重复或包含未知节点时返回不可读，不归一化为无旗标。本地旗标筛选不请求其他清单，未知项不会被当成已知未标记；筛选提示保留已加载范围。新增事项时退出筛选，避免新事项被过滤后消失。

优先级只读标题格前的独立 `gridcell`：空格为无优先级，唯一直接 `span.priority[data-priority-level]` 的 1、5、9 分别为高、中、低；未知值、多个图标、额外文字或缺少结构返回不可读。不读取记录模型的 Priority，不打开详情来填充列表。优先级进入内容指纹，外部变化使旧完成、文字和旗标请求失效。按优先级排序仍移动主子事项组，同级保持原序；升降序均把明确无优先级放在有优先级之后，不可读再列末尾。

[Apple 新版提醒事项说明](https://support.apple.com/en-gb/guide/icloud/mmc0cd77d9/1.0/icloud/1.0)区分旧版可编辑优先级与新版仅可查看。本次专用同步事项详情有一个优先级信息区，内容为“无”，没有输入、选择、按钮或可编辑控件，已取消且未保存。客户端没有新增优先级写命令；高、中、低图标及排序目前只有合成证据，真实端只验收明确无优先级及本地菜单，不据公开脚本结构宣称所有等级真实通过。

## 当前清单的日期视图

界面的“今天／计划”是当前清单已加载快照的本地投影，不能代替原生的全账户智能列表。[Apple 的智能列表说明](https://support.apple.com/zh-cn/guide/iphone/iphe882772ed/ios)将今天和逾期纳入今天视图；本地今天包含可确认日期不晚于本机当天的未完成事项，计划包含有可读日期的未完成事项。不查询其他清单、详情、账户状态或私有接口，不从附注猜日期。“已完成”仍使用原有官方显示入口。范围说明始终可见，未知日期不当作无日期；数量的“＋”表示仍有待核对项目，不是完整总数。

全天日期按公历日比较，指定时间的日历日必须与读取时本机时区一致；系统时区变化或时区不可解释时，不拿旧时间归入今天。每 30 秒及窗口重新获得焦点时更新本机当天；切换视图也立即更新，不发起账号读取。搜索、旗标和排序可组合，排序仍保留主子分组；匹配子项时保留已加载祖先作为灰色只读定位信息，禁用完成与编辑，不计入匹配数，不虚构尚未加载的祖先。

选择今天或计划不发 IPC，也不设置官方筛选或事项字段。新增始终回到当前清单的未完成视图，不为匹配筛选暗中添加日期；保存日期后不再符合筛选的事项自然离开当前投影。日期、祖先、跨午夜及时区规则以合成数据验证；固定真实清单的专项只切换视图、显示不可读日期提示并恢复未完成，再读取核对原指纹，无业务写入。

清除带指定时间的日期时，先取消时间并等待官方控件确认，再关闭日期；保存前要求读回无日期和无时间，只存储一次。不能把时间控件被隐藏当作时间已取消。原事项的历史清除验收入口已退休；新修复入口仅接受重新读取的固定旧时间和详情来源，等待正式 `setSchedule` 回执，不靠后续读空把不确定结果升级为成功。

## Windows 安装与升级

安装器使用固定 electron-builder 26.18.0 和 NSIS，先由原便携包脚本生成全新的公开载荷，再从其应用目录构建；版本读取根 `package.json`，不改 Android 的独立 manifest 版本。固定应用标识、名称及原有系统会话位置，升级不导入或迁移 Cookie。构建前后检查路径、符号链接及所有公开文件散列，关键桌面代码、唯一适配器和 HBuilderX 产物必须一致。会话、凭据、测试目录或依赖目录出现时，在散列文件内容前停止，不将已运行的程序目录直接打进安装器。

测试安装器配置为本用户安装，创建开始菜单入口，不创建桌面快捷方式、不自动启动、不发布自动更新，默认卸载保留应用自身系统会话目录；官方认证过期仍需自行登录。安装及卸载使用固定程序名的只读进程检查，运行中或查询无法确认时停止，不关闭、终止或重放客户端操作。检查脚本明文保留在 `build/windows`，构建时以 UTF-16 编码嵌入 NSIS，避免中文命令行引号歧义，不读取进程命令行、窗口内容或任何会话文件。

当前安装器不签名，也不自动发现或使用证书；保留原始 Electron 运行时，不将其厂商签名当作本项目发行签名。`--publish never` 与空发布配置禁止构建时发布。基线与候选产物、安装/升级/卸载、正常重启、真实登录和独立云端核对分别记录，不以安装器构建成功代替客户端可用性。[NSIS 官方命令行说明](https://nsis.sourceforge.io/Docs/Chapter3.html)规定静默安装的绝对目录参数必须放最后；自动验收先核实该目录位于本项目专用测试根中。

## 写入结果

网页控件需要完整的指针交互序列。调用单独的 `click()` 在真实 iCloud 中不一定生效，适配器对此有回归测试。

适配器先核对当前页面与内容，再提交一次交互。观察到网页状态更新时返回 `WEB_STATE_OBSERVED`，同时明确 `cloudConfirmed: false`。没有回执时返回 `UNCERTAIN_WRITE`，清除旧快照的写权限，不重新点击。

这避免在网络不稳定或重复提醒生成下一次事项时误重放操作。首版不自动补偿、不合并离线写入。

Windows 删除分为只读预检与明确确认后的 `deleteItem`。预检核对当前清单、记录 ID、指纹、完成状态、已加载行数与位置语义，仅支持不超过 80 行且没有子项/重复规则的单项。原官方文字编辑或其他详情未结束时停止；只打开自己的详情核对重复信息，再取消，不存储。随后使用官方 Home/ArrowDown 键盘导航形成排他单选，逐步核对焦点和选区；没有使用网页内部选择或删除模型。80 行上限用于控制预检耗时，长清单、部分加载、父项及批量删除仍保留官方入口。

本地确认界面显示具体标题与同步删除影响，默认聚焦取消；普通回车取消，Esc 可退出，只有明确激活确认才提交。正式命令要求 `confirmed: true` 和本次请求标识；提交前再次预检，用同一官方行派发一次 Backspace。请求标识在本页去重，超时或异常不重放。只在目标消失、清单仍一致、其他已加载事项指纹全部保持时报告网页移除，仍为 `cloudConfirmed: false`。层级和展开状态也进入所有字段共用的内容指纹，确认期间目标结构改变会拒绝旧请求。

文字编辑进入官方控件的编辑状态后再次检查指纹。Chromium 原生编辑命令不发出 `beforeinput`，因此先通过标准输入事件准备选区，再执行一次原生命令；多行文字完全转义为仅含换行的片段，避免多次 `input` 破坏网页富文本范围。没有原生失焦事件时只补齐离开编辑事件，不重做输入。原生命令抛错、网页接管或结果未知均停止，不直接设置正文来重试。Android/鸿蒙尚未开放该命令，不能用 Windows 结果替代移动端验证。

桌面诊断仅保留静态页面路径、主机和固定错误类型，服务接口省略整个路径及查询，不保存账户标识。图形程序启动端的标准流断开不应弹出异常并阻塞主进程；标准流保护有真实子进程断管回归。

开发模式被动监听 Chromium 异常事件，只提取 Apple 公开静态脚本的行列号，不读取异常正文、变量、参数或远程对象。主动异常暂停曾改变网页时序，已撤销，不进入当前实现。

新增阶段诊断只包含本地数字序号和固定枚举，页面退出后的迟到回执只能合并到同一次操作，不能污染后续写入或当作云端确认。未取得派发状态时保留 `null`，不报告为没有派发。后续只读不会抹掉最后写入阶段。

正式客户端与 Electron 合成验收使用同一个 `ipc.cjs`，校验主窗口、主框架和固定服务区域。普通模式不依赖开发参数，也不启用阶段诊断。官方窗口隐藏时关闭浏览器后台计时器节流，以维持官方自动保存；主界面仍保留日常节流。此项不等于本地列表后台同步、应用退出或系统睡眠期间的保存保证。

Windows 手动重新连接也经过同一受限 IPC。在同一个官方窗口中依次载入固定服务区域的根入口和提醒事项入口，不读取、清除或复制会话，不调用网页内部同步服务。导航每步只执行一次，超时停止加载；操作期间禁止其他命令。先用 `readLists` 等待新页面的导航元数据，不读取默认清单的事项；原清单名称唯一时仅选择一次，新清单尚未加载只用 `readList` 核对新页面和指定选区后读取。缺失或同名时保持只读，要求用户重新选择；选择变化立即停止。删除或重连后需要手动选择时，刷新也只读导航，不能回退到官方自动改选的事项。页面或清单再次变化则停止，不能复用旧句柄写入。

官方 `beforeunload` 阻止离开时返回 `OFFICIAL_PAGE_BUSY`，保留原窗口，不忽略保护或继续第二步。每轮诊断只保留序号、固定导航阶段、是否提交/阻止、路由类别及错误枚举，不保留 URL 或异常正文；监听随本次导航结束清理。真实写入后的重新连接已复现根入口阶段被阻止，但不能据此解释全部历史间歇失败。依据 [Electron 文档](https://www.electronjs.org/docs/latest/api/web-contents#event-will-prevent-unload)，该事件中的 `preventDefault()` 会忽略页面离开保护，本项目不调用它。前端及验收信箱分别保留固定失败阶段，避免汇总时丢失原因；不自动重试导航或事项修改。

清单快照新增名称/颜色指纹，仍使用当前页面内的弱引用句柄，不以同名定位写入。Windows 新建和重命名绑定当前页面、当前清单及其指纹。新建只激活一次官方添加按钮；重命名从当前清单菜单打开列表信息，并核对详情中的原名称。只向指定名称输入框发送一次标准输入事件，完成按钮仅提交一次；不调用网页内部创建或保存方法，不触发颜色/图标控件。名称限 100 字符，请求标识在本页去重。观察新建时要求仅增加一个新句柄、自动选中且旧清单指纹保持；重命名要求同一句柄目标名称、颜色和其他清单及事项指纹保持。无准确回执则停止并要求读取核对。

清单编辑器支持取消、输入法选字与回车提交，创建后退出搜索和旗标筛选。该能力只在 Windows 正式桥接开放；普通浏览器示例不冒充账号清单管理。自动验收严格绑定原固定测试清单或两种已知管理测试清单名称，增加另一个同前缀清单后也不能将它替代原清单。信箱中断分类集中列举所有写命令，删除、新增删除测试事项及清单写入异常均保持不确定状态。

清单删除先在本地显示具体名称、全部事项及同步设备影响，包括尚未加载内容，默认聚焦取消。明确确认后才打开官方删除菜单和确认框；核对页面/清单指纹、非共享确认的完整标题、唯一可见的取消与破坏性删除控件。排除无障碍隐藏的按钮测量副本，不接管已有弹窗或文字编辑。共享、标题冲突及控件未知时取消自己的确认并停止；请求在激活删除入口前登记，菜单与最终删除各一次，不调用内部删除接口。只有目标消失、其他清单指纹全部保持才报告网页移除，仍不提升为云端确认。

Windows 清单外观使用独立能力与固定 `getListAppearance` / `setListAppearance` 命令。先打开列表信息，核对名称、当前颜色及图标，投影可见选项后取消；用户在本地选择并保存时重新打开，核对页面、清单与选项集合指纹。只选择发生变化的颜色/图标各一次、完成一次，不修改名称；草稿拒绝、内容变化或保存未知时停止并先读，不回退为其他写入方式。清单指纹包含图标特征，外部图标变化同样使旧名称或删除请求失效。

图标从公开 SVG 控件投影静态几何：固定标签与属性白名单、路径/变换字符约束、大小和节点上限，规范化同一图标内部的 ID、引用与蒙版。不复制 HTML、脚本、样式、事件、外链或网页内部状态；本地以编码 SVG 图片显示，不插入 HTML。选项未知或不能准确匹配当前图标时保留官方入口，自定义表情尚未开放。颜色和图标分别为单选组，支持 Tab、方向键、Home/End、回车/空格与 Esc 取消；选择阶段没有云端写入。

Windows 子事项使用官方单选和键盘入口，不调用内部父记录或更新方法。只接受最多 80 行、两级顺序、组内位置/数量及父项标记都可核对的当前清单；父关系从同一 DOM 行组的前序主事项推导并进入事项指纹。预检打开并取消目标和父项详情，拒绝重复规则及已有编辑，再通过 Home/方向键形成排他单选。缩进目标不能已有子项或与父项完成状态不同；提升时按官方快捷键行为列出会归入被提升事项的后续同级子项。

本地层级确认默认取消，回车在默认焦点与 Esc 均取消并恢复行按钮焦点；明确确认才重新预检和比对全部层级/内容指纹，发一次平台对应的缩进或提升键。不确定时不重放。结果需保持所有记录 ID、顺序、正文、日期、完成/旗标/优先级等字段，父关系必须精确符合计划；网页观察仍不代表云端保存。窄屏行按钮移至标题下方，避免子事项缩进后挤压正文。新增跨清单移动仍没有开放：当前账号详情只有只读清单信息，不能将复制再删除冒充移动。

层级预检停止时返回固定 `subtaskStage`：`structure/plan/active-editor/details-cancel/recurrence/selection-start/selection-step`，说明应核对结构、结束编辑、关闭详情或重新核对选区；仅白名单值进入受限验收汇总，不包含控件文本、账户数据或异常正文。全部这些阶段发生在层级修改快捷键之前，回执明确 `dispatched: false`，不以失败为由自动重试。真实一次创建/日期编辑后的旧版预检停止，冷启动后通过；旧版没有阶段证据，不能据此认定具体原因或宣称此类间歇问题已修复。

删除后不自动读取官方可能改选的另一份事项。`readLists` 和删除结果仅提供导航快照，清除旧事项写权限；用户从本地侧栏明确选择后才读取事项并恢复编辑。无清单时通过官方空列表提示和添加按钮识别账户空状态，仍保持已连接；允许新建第一份，成功选中新清单后解除选择保护。真实验证只删除既有专用空清单，非空清单、最后一份及首次空账户只具合成证据；共享清单保留官方入口。

此入口由官方重载后仍显示旧旗标的真实问题驱动。[Apple 的同步排查](https://support.apple.com/en-ie/102543)建议在 iCloud.com 打开另一应用再返回。项目采用“根入口再进入提醒事项”是本地实验推导的路径，与该建议不完全相同；没有访问其他私人应用内容。专用旗标两方向更新经另一 Windows 会话实测可读，不能据此承诺长期后台同步、所有字段一致或日期清除已恢复。

H5 在本地界面捕获原始键盘事件，保留中文输入法 `isComposing`，避免组件包装后把选字回车当作保存。Ctrl+N 和 Ctrl+F、Esc 取消均经过实际构建界面验证；这些监听不会装入远程官方页面。

## Android 窗口与请求生命周期

`lib/android-bridge.js` 在 `APP-PLUS` 分支内实现原生容器；`lib/bridge.js` 只在该分支导入它和唯一适配器源文件。远程页面使用 `plusrequire: none`，按[HTML5+ 官方说明](https://www.html5plus.org/doc/zh_cn/webview.html)不注入 5+ API。

命令发出前先检查是否忙碌，再考虑创建或切换窗口。执行期间不允许切换区域、重新加载或派发另一命令，但可以显示同一官方窗口供使用者核对。加载、错误、关闭及超时均结束对应请求；若是写入，返回 `UNCERTAIN_WRITE`，不再派发。旧窗口事件、旧请求回执不能改变新窗口的就绪状态或解除读取要求。下一次更改必须先成功读取当前页面。

返回通道只接收当前窗口和请求匹配的固定结构；限制 URL 编码后的消息长度，避免中文正文扩大传输体积。超过范围时不拆分重发，不把网页回执提升为云端保存证据。合成测试覆盖这些事件顺序及共享适配器的实际读写，但原生事件触发顺序、URL 长度上限、隐藏窗口执行和登录仍必须在 Android 真机验证。

## HarmonyOS 原生容器与共用协议

标准 uni-app Vue3 按 [DCloud 原生组件文档](https://uniapp.dcloud.io/tutorial/harmony/native-component.html)通过 UTS 引入 ETS，在本地页面使用 `embed`。`uni_modules/suixing-arkweb` 注册 `suixing-icloud`，内层 ArkWeb 只载入官方 HTTPS 页面，不注入 uni SDK、JavaScript 原生代理或系统权限，不放宽证书和混合内容检查。

`lib/harmony-bridge.js` 管理固定区域、原生实例标识和单个在途请求；`HarmonyICloudHost.vue` 更新整个 options 对象，将原生事件传回逻辑层。工具栏与页面返回事件只隐藏官方容器，保留实例；关闭或渲染退出则清除实例。切换区域时创建新实例，旧实例事件不能影响当前请求。

Android 和鸿蒙通过 `lib/native-protocol.js` 共用命令白名单、回执校验与注入脚本，脚本仍来自唯一的 `static/icloud/adapter.js`。ArkWeb 只在当前官方主页面拦截受限回执 URL。命令去重、不确定写入先读、超时和迟到回执的规则与 Android 一致，不自动重发。

9 项鸿蒙逻辑测试包含共享适配器在合成页面的实际单次写入；HBuilderX 资源已包含插件注册、UTS 转换后的 ETS、原生组件源文件和共用页面调用。资源导出不会完成原生组件编译，尚需 DevEco/HarmonyOS SDK 编译 HAP，随后验证官方登录、隐藏实例执行、返回手势和真实读写。
