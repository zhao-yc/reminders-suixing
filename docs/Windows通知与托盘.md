# Windows 通知与托盘

更新：2026-11-05。本分支基于 PR #3 的当前清单自动更新，位于独立工作树；根版本为 0.1.3 候选，共用适配器 0.3.17。主工作区原生新增观察继续运行，本工作树的构建、配置与合成数据不替代它。

## 使用行为

通知默认关闭。在侧栏“系统通知”中开启后，关闭窗口会隐藏到托盘；托盘可打开随行、关闭通知并停止后台运行，或退出应用。退出后停止提醒，下一次启动仍须明确读取并选中清单。

后台每 15 秒定向读取当前页面、当前清单，先核对连接、官方选区与编辑状态。提醒范围限这份清单在网页中已经加载、尚未完成且日期可确认的事项。编辑、连接待核对或选区失效时暂停；出错后必须手动刷新，重新得到明确读取代次后才恢复。更换清单不是全账户后台同步。

指定时间按读到的时区换算；日期无效、时区未知、时钟跳过的分钟或云端时间缺偏移而存在重复小时，均不猜测，显示待核对数量。全天事项使用用户设置的本地时间，默认 09:00，跟随系统时区；若重复小时出现，全天本地时钟只取第一次。规则文字不会生成未来重复事项。

启用前已经到期的内容不补发。同一进程中，启用后到期而因编辑、连接或休眠延后的事项，重新就绪并读取当前未完成状态后可以提醒；已经消费过的本轮不会因反复读取、切换清单或时钟回拨重发。通知显示失败或没有回执也不自动重发。应用重启后的去重历史不落盘，以新的启用时刻为界。

同一轮到期事项聚合为数量通知，系统正文不含事项标题、备注或日期。点击只返回应用，完成和编辑仍在客户端进行。Windows 勿扰、系统权限和通知中心是否实际呈现，不能只由 API 支持状态推断；设置中可发送固定测试通知。

## 实现与隐私

`identity.cjs` 的固定 AppUserModelID 同时提供给应用和安装器，与开始菜单标识一致；参见 [Electron Windows 通知要求](https://www.electronjs.org/docs/latest/tutorial/notifications#windows)。收到 [`show` 事件](https://www.electronjs.org/docs/latest/api/notification#event-show)才记录显示回执，失败和超时只返回固定结果，不输出系统原始错误。

到期检查与托盘都在主进程，隐藏窗口不依赖渲染计时器。后台读取使用共享适配器已有的 `readList/background`，没有新私有接口、账户写入或远程网页权限。前台命令若遇到已经开始的通知读取，等待该次有界读取结束后只提交原命令一次；不建立离线业务队列。页面仍按原指纹和一次写入规则保护。

设置文件 `notification-preferences.json` 只保存开启布尔值与全天时分。读取结果仅在处理期间用于判断，去重键仅留在内存；个人正文、记录 ID、日期和登录凭据不写入设置或系统通知。托盘 PNG 由固定几何脚本生成，打包时纳入关键字节核对。

新增原来会保留官方输入焦点，合成实测 `WEB_STATE_OBSERVED` 后后台仍返回 `AUTO_READ_DEFERRED`，会拖住同清单其他到期提醒。0.3.17 仅对已观察、本次唯一新增、同一清单同一节点且标题不变的原输入框继续只读；没有新增写、失焦或提前结束官方自动保存。再次输入、输入法开始、其他写入、断网或版本清理撤销，其他编辑标志及弹层仍暂停。此修复的真实 Apple 新增后续通知还需单独验收，不能由合成得到云端保存结论。

- 350 项行为测试通过：日期/时区与夏令时歧义、未知数据、到期聚合、去重、延后恢复、迟到结果、手动读取恢复门槛、严格设置类型、托盘、前台等待、固定文案，以及新增保留焦点、输入/输入法撤销、弹层与断网拒绝。普通日期、层级、连接与原有行为回归也保留。
- HBuilderX 5.34 于 13:24:26 发布本树 0.3.17 Web；主工作区 Web 仍是 11:49 的原文件。不是直接 Vite 或浏览器代替桌面。
- 正常运行路径的原生合成专项：全新无账号配置，不创建官方页面；Windows 固定测试通知取得 show 事件，真实托盘创建、关闭隐藏、同一实例恢复、关闭通知移除托盘、391 宽度与窄屏入口通过。截图只含应用空白欢迎/设置内容。
- 合成网页与虚拟时钟专项：正式 UI 单次新增第三项并保留官方输入焦点；开启通知、隐藏到真实托盘后，两个既有到期合成项聚合为一次 Windows show 回执。重复检查不再次派发，通知链不追加业务写入。早次测试计数变量被新增布尔值遮蔽，修正后通过，不能把早次断言失败记为通过。
- 0.3.17 真实系统时钟专项也已通过：保留单次合成新增后的输入焦点，不修改系统时钟；真实 15 秒计时器在隐藏状态读取两个既有到期项并取得一次系统 show，再等一轮仍无第二次派发或额外业务写入。
- 原有完整 Electron 回归单独通过，覆盖编辑、日期、旗标、清单、层级、连接中断、键盘、窄屏与隔离。

相关忽略日志在本工作树 `.local/windows-notifications-*.txt`。原生合成用 `node scripts/verify-native-notifications.mjs`，虚拟时钟闭环用 `node scripts/desktop-smoke.mjs --notifications`，真实系统时钟用后者再加 `--real-clock`；普通完整回归仍保留 55 秒上限，只有真实时钟专项延长等待。
