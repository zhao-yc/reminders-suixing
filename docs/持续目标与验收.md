# 持续目标与验收

更新：2026-11-04。目标保持 uni-app Vue3，以 Mac/iPhone 提醒事项的日常工作流为验收基准，交付 Windows、Android、HarmonyOS 实际可用客户端。下列阶段是验收门槛，不是完成声明。原电脑已取得的证据见[最小验证记录](最小验证记录.md)，不能替代虚拟机或手机验收。

## 阶段

| 阶段 | 可验收结果 | 当前状态与下一步 |
| --- | --- | --- |
| 1. 复现工程 | 同步 main、固定 HBuilderX、行为测试、Web 构建、Electron 合成验证 | 虚拟机已恢复 70c19e3；Web 构建和 Electron 合成验证通过；诊断超时回归已补充 |
| 2. Windows 最小真实闭环 | 先只读核对中断事项；自建界面完成/取消完成各单次操作；官方重载和独立客户端核对 | 虚拟机尚未登录 iCloud；不重放原电脑中断点击 |
| 3. 会话可靠性 | 用户选择官方保持登录/信任选项后，正常退出、重启和设备重启仍可读；过期时能重新登录 | 原电脑免登录失败；保留内置会话存储，不导入或另存 Cookie；先建立复现实验再修改 |
| 4. 日常编辑 | 清单/事项新增、改名、备注、日期、删除；写入一次、冲突拒绝和云端重载 | 需基于真实官方 DOM 调研后实施；删除须按实际工具要求确认 |
| 5. 整理与复杂事项 | 优先级、旗标、子任务、重复、搜索、排序、智能视图 | 先明确网页实际支持；只基于已加载内容的视图明确标识范围 |
| 6. Android | 独立安装包、官方登录、共享适配器、返回导航、会话、真实读写与云端核对 | 原电脑只导出资源；虚拟机尚无设备证据 |
| 7. HarmonyOS | 独立原生桥接、不使用 plus、安装包、登录、真实读写与云端核对 | 桥接待实现；资源导出不能代替桥接、HAP 与设备验收 |
| 8. 系统体验与发行 | 后台同步、通知、小组件、键盘/触控、离线状态、恢复、安装/升级 | 分平台实测；依赖系统能力或官方限制的项目逐项记录，不以外壳宣布体验对齐 |

阶段 2 的认证或设备等待期间，可推进不依赖真实数据的行为测试、平台接口、工具链与交互改进；不得以合成结果越过真实验收门槛。每段经必要验证后提交中文 commit，检查上游后合入并推送 main，不强推。

## 功能与交互差距

参考依据于 2026-11-04 查阅：[Apple iCloud 提醒事项手册](https://support.apple.com/zh-cn/guide/icloud/mmc0cd794a/icloud)、[iPhone 提醒事项](https://support.apple.com/zh-cn/102484)、[Mac 提醒事项手册](https://support.apple.com/zh-hans/guide/reminders/welcome/mac)。官方手册用于明确原生基准；网页是否暴露可适配控件仍须在对应账户和版本中实测。

| 工作流 | 当前客户端 | 实现路径与验收要点 |
| --- | --- | --- |
| 清单切换与加载 | Windows 已有真实读取；只覆盖当前已加载内容 | 验证长清单、隐藏完成项、子任务展开；缺少项目不可当作删除 |
| 完成/取消完成 | 唯一共享适配器、记录 ID/指纹与明确目标；取消完成真实结果待核对 | 单次发送、状态不确定先读；重复事项生成下一条时不得自动补偿点击 |
| 清单/事项新增编辑删除 | 未实现 | 官方网页 DOM 调研；先合成协议和冲突测试，再只操作专用测试数据；删除按确认要求执行 |
| 备注、日期、时间、URL | 备注和日期文字只读 | 定义结构化字段、时区和全天语义；不能把任意日期文字解析成可靠提醒时间 |
| 优先级、旗标、子任务、重复 | 未实现；子任务仅显示层级标记 | 各字段单独验证；重复规则和下一实例要经云端核对 |
| 搜索、排序、智能列表 | 搜索当前已加载清单标题/备注；完成页签 | 全局搜索需完整数据来源；今天/计划/旗标视图不得把部分加载数据冒充全账户 |
| 附件、图片、扫描件 | 未实现 | 核实网页可读写能力和安全文件选择；无法支持时保留官方入口并列明差距 |
| 共享、分配与协作更新 | 未验收 | 更新版提醒事项的网页共享管理可能受限，见[Apple 共享限制](https://support.apple.com/zh-cn/guide/icloud/mm4bb3fa6e/1.0/icloud/1.0)；不得伪造管理能力或自动发邀请 |
| 后台同步与离线 | 手动刷新；失败保留显示并禁止旧快照写入 | 先解决会话与可见性；断网与冲突需可恢复，不能排队重放不确定写入 |
| 通知、位置提醒 | 未实现 | 各系统通知授权、后台限制、时间变化与应用退出分开验收；网页通知不是原生通知的证据 |
| 小组件、快捷入口 | 未实现 | 按平台原生扩展评估；数据新鲜度、点击直达和完成回执需实测，参见[Mac 小组件基准](https://support.apple.com/zh-hans/guide/reminders/remn83e1a96e/7.0/mac/27) |
| 键盘、触控、无障碍 | 桌面分栏/窄屏抽屉，少量辅助标签 | 焦点、键盘完成/新建、点击区域、读屏、缩放、安全区、软键盘与返回手势各端验证 |

## 会话实验记录要求

不读取 Cookie 内容。每次只记录：系统与构建版本、同一应用/数据目录是否复用、用户是否手动选择官方保持登录/信任选项、正常退出/重启路径、启动后是否需要认证、能否只读取得专用测试事项。测试包含关闭官方窗口后继续读取、主窗口正常退出后重启、设备重启及官方会话过期。无凭据自动填充、外部浏览器会话复制或导出机制。

如需新密钥或签名证书，保留安全原件并按用户备份约定处理；当前迁移与工具链恢复未产生项目密钥或证书，不提交依赖、产物、日志或会话。
