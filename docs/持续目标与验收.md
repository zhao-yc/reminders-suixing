## Android 真机验收顺序

1. 安装与 PR 提交及散列对应的测试 APK。记录 Android 和 WebView 版本，由账号持有人在官方页面完成登录与验证。选中专用测试清单后，通过系统返回回到应用，再刷新核对。
2. 先核对只读路径。关闭并重开应用后检查同一会话能否读回专用清单；断网期间确认界面只读，联网后手动重连，确认只恢复原清单。进入「已完成」核对已加载内容，确认重复查看不改变任何事项的完成状态。在另一个苹果设备产生新的专用测试变更后，分别核对 Android 前台空闲、切到后台及保留官方草稿的自动更新表现。
3. 在专用清单内逐项测试一个以「随行验证」开头的临时事项。每次只提交一次，依次核对新增、标题、备注、旗标、日期时间、清除日期和完成状态。若回执不明确，先在官方页面只读核对，暂停后续修改。
4. 每次测试保存后，分别记录 Android 官方页面重载和独立 Mac 或 iPhone 读回的结果。最后在清单完整加载时，可确认删除刚才创建的临时事项，并在两端核对仅该事项已移除。只记录结果是否一致，避免将提醒内容或账号凭据写入记录。

## 会话实验记录要求

不读取 Cookie 内容。每次只记录：系统与构建版本、同一应用/数据目录是否复用、用户是否手动选择官方保持登录/信任选项、正常退出/重启路径、启动后是否需要认证、能否只读取得专用测试事项。测试包含关闭官方窗口后继续读取、主窗口正常退出后重启、设备重启及官方会话过期。无凭据自动填充、外部浏览器会话复制或导出机制。

区域选择通过 uni-app 的固定非账号设置键保存，只允许 `cn/global`；设置读取失败时回到默认区域，写入失败则明确提示下次重新选择。窗口再次启动只聚焦原主界面，不再强制打开中国大陆官方页面。区域恢复的合成证据不等于新增任何账号登录或长期会话证据。

如需新密钥或签名证书，保留安全原件并按用户备份约定处理。本机已生成 Android 专用测试密钥，原件只在已忽略并限制权限的本地目录；用户指定的 E 盘备份目录不存在，因此尚未备份，不得宣称完成备份。不提交密钥、密码、依赖、产物、日志或会话。
