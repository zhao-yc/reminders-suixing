# 虚拟机接续说明

更新：2026-11-04。此文件用于另一台电脑或虚拟机中的 Codex 接手，**不是全部验收完成的声明**。当前虚拟机结果见下文；原电脑的历史证据仍保留在[最小验证记录](最小验证记录.md)。

## 项目与约定

- 项目名：提醒事项·随行。
- 仓库：https://github.com/zhao-yc/reminders-suixing 。默认交付分支：`main`。
- 原电脑目录：`E:\git\提醒事项·随行`。虚拟机可以使用自己的目录，不要硬编码原电脑路径。
- 固定工程：`apps/uni-app`，**uni-app Vue3，不能改成 uni-app x**。
- Windows：Electron 承载同一工程的 H5 产物。Android：5+ WebView。鸿蒙：独立 UTS/ETS ArkWeb 桥接已接入，原生编译及设备待验，不能使用 `plus`。
- 先阅读仓库 `AGENTS.md`，使用中文文档、注释和提交信息。构建、预览走 HBuilderX CLI，不直接运行 Vite。
- 外置浏览器默认 ego lite。开发和测试不使用本机 Docker；本任务当前也不需要 Docker。

## 已确认的结果

1. Windows 原来的密码登录连接错误已解决。关键修复是：在创建任何窗口前设置 `app.userAgentFallback`，并统一会话、窗口标识。只设置 `session.setUserAgent` 时，跨域 Apple 登录 iframe 仍带中文应用名和 Electron 标识；统一后真实登录通过。
2. 用户自行完成密码和双重认证。Windows 客户端真实读取成功：6 个清单、当前清单已加载的 26 条事项。这不是全部账户数据量。
3. 专用测试事项经 Windows 共享适配器单次标记完成，返回 `WEB_STATE_OBSERVED`。另一个独立登录的 ego 浏览器重载后读取到 `completed: true`，确认保存到了云端。
4. Windows 自建界面中实际点击“刷新”，显示已连接并读到真实数据；点击“已完成”页签后显示专用测试事项。
5. 虚拟机本轮 40 项行为测试、最新 Electron 合成检查、HBuilderX Web 构建和 Android 资源导出通过。13 项新增 Android 桥接回归覆盖窗口切换、导航、关闭、超时、迟到回执与共享适配器执行；没有 APK/HAP 或真机验收。
6. 虚拟机用户已自行登录。原中断事项先只读确认未完成，随后经本地界面完成、取消完成各单次操作；两次官方重载后均只读核对成功，最终恢复为未完成。本轮独立 iPhone/Mac 核对仍待反馈。
7. 虚拟机客户端正常退出并启动新进程后，复用内置会话目录，无需再次认证即可读取并定位专用事项。本次一次应用重启通过，设备重启、长期会话和过期恢复待验；原电脑未保持登录的历史失败仍有效。
8. 新增鸿蒙 ArkWeb 原生容器与逻辑桥接，共用固定命令协议和唯一适配器；全套 49 项行为测试通过，其中鸿蒙逻辑层 9 项。鸿蒙资源导出成功，产物包含插件注册和 ETS；本机未配置 `hdc`、`ohpm`，ETS/HAP 原生编译及真机均未验收。

- 便携包已生成并启动；图形工具枚举时用户按 Esc 停止。不要自行恢复图形输入，先继续代码工作；包内界面与独立账户尚未验收。

## Windows 虚拟机启动步骤

建议复用已验证的 HBuilderX `5.34.2026102909`；需要 Node.js 22+（CI 使用 Node.js 24）、Git 和可访问 npm/GitHub/Apple 官方站点的网络。

```powershell
git clone https://github.com/zhao-yc/reminders-suixing.git
cd reminders-suixing
git status --short --branch
npm ci
npm test

# 改成虚拟机内真实的 CLI 路径，不照搬原电脑的 D 盘路径。
$env:HBX_CLI = 'D:\HBuilderX\cli.exe'
& $env:HBX_CLI version
powershell -ExecutionPolicy Bypass -File scripts/hbx.ps1 -Action publish-web
npm run desktop:smoke
npm run desktop:start -- --verify-live --open-icloud
```

HBuilderX 固定工程为克隆目录下的 `apps/uni-app`。Web 产物位于该工程的 `unpackage/dist/build/web`，由 Electron 的安全本地源加载；普通浏览器预览不能代替独立客户端验收。启动前检查相同项目和端口，已运行就复用。

用户在官方窗口自行完成登录及双重认证，然后回到主界面刷新。官方网页默认可能隐藏已完成事项；可在清单右上角“编辑提醒事项列表”菜单中选择“显示已完成的项目”，再读取。事项不显示不能作为未保存或已删除的证据。

桌面日志在启动终端；关闭主窗口正常退出。`--verify-live` 的固定命令信箱及限制见 [最小验证记录](最小验证记录.md)。不要直接运行写命令来测试环境是否正常。

如果虚拟机是 Linux/macOS，可做代码、行为测试及部分 Web 工作，但不能据此宣称 Windows 客户端验收通过。
