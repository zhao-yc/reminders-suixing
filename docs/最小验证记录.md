# 最小验证记录

验证日期：2026-11-04。固定工程为 uni-app Vue3，HBuilderX 5.34.2026102909；Windows 使用 Electron 45.2.2。

## 登录故障及修复

症状：Windows 独立客户端在输入密码后显示“连接服务器时出现问题”。诊断没有读取输入框值、Cookie、认证头或请求体。

发现：`session.setUserAgent` 只改变了主页面的标识，跨域 Apple 登录 iframe 的 `navigator.userAgent` 仍包含默认的中文应用名和 Electron 产品标识。仅调整会话标识、存储权限或尝试 Safari 标识均未解决。

修复：在创建任何窗口之前设置 `app.userAgentFallback`，并统一会话与网页容器的标识。实际 Apple 登录 iframe 已核对为纯 ASCII 的真实 Chromium 版本标识。网页安全、沙箱、证书验证和官方域名限制保持启用。

修复后，使用者在 Windows 官方网页窗口自行完成密码与双重认证，真实账户成功登录。客户端已读取 6 个清单及当前清单已加载的 26 条事项；这里的数量不是账户全部数据量。

退出时调用 Chromium 的内置存储刷新，不读取、另存或更改 Cookie。**本次正常退出并重启后仍需重新登录，免登录尚未通过，内置存储刷新没有解决该问题。** 不从其他浏览器导入会话，也不另存 Cookie。

## 限定诊断通道

`--verify-live` 仅开发模式可用，不监听网络端口。它读取已忽略目录 `.local/verification-command.json` 中的固定命令，并将数量、布尔状态或去除查询参数的诊断结果写到 `.local/verification-result.json`。没有任意脚本、任意地址、凭据或个人数据导出接口。

例如，写入 `{"requestId":"read-1","command":"read"}` 可进行只读核对。支持 `diagnostics`、`open-sign-in`、`read`、`select-test-list`、`show-completed`、`complete-test-item`、`uncomplete-test-item`、`reload`、`quit`。写入命令必须先通过唯一测试清单、唯一测试事项及当前页面的范围检查；底层仍使用共享适配器的记录 ID 与指纹检查。

辅助脚本还存在未解决问题：`show-completed` 曾返回 `TEST_ITEM_NOT_VISIBLE`，随后前台显示时才看到事项；完成按钮验证中的 `.tabs button` 没有覆盖 uni-app H5 的 `uni-button` 标签，曾返回 `TEST_UI_NOT_READY`。它们尚不能作为可靠的自动验收入口。上述失败均未派发事项写入；最后一次原生界面取消完成的结果仍不确定。

迁移检查点只重新运行不打开图形界面的行为测试。先前 Web 构建和 Electron 合成检查已经通过，但之后增加的诊断辅助脚本不在这些已通过检查的覆盖范围内。

## 后续边界

- 首版只读取当前网页已加载数据；隐藏的完成事项需先在官方页面展开。
- 网页上的即时变化返回 `WEB_STATE_OBSERVED`，不冒充云端保存确认。持久化需重载或在另一独立登录客户端读取核对。
- 暂未验证共享清单、重复提醒生成下一次事项、附件、完整智能列表、离线编辑、后台同步及通知。
- 不以外置浏览器、合成页面或移动资源构建替代独立客户端和真机验收。

## 虚拟机真实读写、会话及 Android 桥接验证

日期：2026-11-04，HBuilderX 5.34.2026102909、Electron 45.2.2；与上节为同一虚拟机，未导入原电脑会话。

- 旧客户端退出后重启了有界诊断版本。主页可加载、运行能力检查正常；未认证阶段的会话校验请求返回 HTTP 421，不能仅据此确定登录错误原因。图形工具恢复后看到 Windows 官方“使用密钥登录”提示在等待 USB 安全密钥；认证步骤由用户自行处理，随后用户确认已登录。
- 客户端只读取得 6 个清单及当前清单已加载的 26 条事项，不能当作账户全部数据。先选择唯一的“随行验证”专用清单，只读确认原中断事项当前为未完成，没有重放原电脑的中断点击。
- 经 Windows 本地界面按钮及受限 IPC 单次标记完成，返回 `WEB_STATE_OBSERVED`、`dispatched: true`、`cloudConfirmed: false`。重载官方页面后已完成分组默认隐藏；限定辅助命令展开分组后只读确认专用事项为已完成。本轮真实“显示已完成”流程已通过，不依赖标题点击事项圆圈。
